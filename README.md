# Conscience Coaching website

Static website for Conscience Coaching and Consulting CIC.

## Branches

- `main`: production
- `andie-working`: preview and approved development work

## Current foundation

The first foundation includes the shared responsive layout and initial pages for Home, About Angela, Services, Events, Blog and Contact.

All preview pages currently include `noindex, nofollow`. Calendly, Formspree, Plynth, final images, migrated blog posts and legal pages will be added in later approved phases.

## Local preview

Run a simple static server from the repository root, then open the local address in a browser:

```bash
python3 -m http.server 8000
```

The site will be available at `http://localhost:8000/`.
